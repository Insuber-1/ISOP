## ขั้นตอนเมื่อได้รับต้นฉบับครบ

1. ยืนยันชื่อเรื่องภาษาไทย/อังกฤษ ชื่อผู้จัดทำ สาขาวิชา หลักสูตร ที่ปรึกษา และปีที่เล่มเสร็จ
2. ระบุไฟล์ฉบับล่าสุดของแต่ละส่วน และรวมเนื้อหาตามลำดับส่วนต้น → บทที่ 1–5 → บรรณานุกรม → ภาคผนวก → ประวัติผู้เขียน
3. ตั้งค่าหน้ากระดาษ ฟอนต์ ขนาดอักษร ย่อหน้า ระยะบรรทัด หัวกระดาษ/ท้ายกระดาษ และเลขหน้าตามชนิดหน้า
4. ตรวจหัวข้อ ตาราง รูป สมการ การอ้างอิง และความสอดคล้องของคำ/ชื่อ/ตัวเลขทั้งเล่ม
5. สร้างสารบัญและบัญชีตาราง/รูปหลังจัดหน้าเสร็จ แล้วอัปเดตเลขหน้า
6. ตรวจไฟล์รวมทีละหน้า รวมถึงหน้าว่าง การตัดหน้า ภาพ/ตารางล้นขอบ และความสม่ำเสมอ ก่อนส่งไฟล์ฉบับจัดรูปเล่มไว้ในโฟลเดอร์นี้
