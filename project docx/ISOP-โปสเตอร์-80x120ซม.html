01 ที่มาและความสำคัญ

ตัวอย่างหน้าจอโปรแกรม

  • ตรวจการใช้ CPU, RAM และ DISK ของเครื่อง พร้อมบันทึกข้อมูลไว้ดูย้อนหลัง
  • แสดงสถานะและกราฟ เพื่อช่วยดูแนวโน้มการใช้ทรัพยากร
  • จัดการ CONTAINER จากไฟล์ DOCKER COMPOSE และเปิด AI RAM ให้ช่วยปรับ RAM อัตโนมัติได้
  • เปิด BACKUP เพื่อสำรองโฟลเดอร์โปรเจกต์ที่นำเข้า (ไม่รวม DOCKER VOLUMES แยกต่างหาก)
ข้อจำกัด: โปรแกรมช่วยติดตามและจัดการการตั้งค่า แต่ไม่สามารถเพิ่ม CPU, RAM หรือพื้นที่จัดเก็บจริงให้เครื่องได้
02 วัตถุประสงค์ของโครงงาน
1.

เฝ้าระวังต่อเนื่อง: แสดง CPU / RAM / Disk, Risk Score, สถานะเสถียรภาพ และแจ้งเตือนเมื่อพบค่าผิดปกติ

2.

ตรวจสอบย้อนหลัง: เก็บ Metrics พร้อม Timestamp ใน CSV เพื่อเทียบค่าเฉลี่ย จุดสูงสุด และช่วงที่มีภาระงานสูง

3.

คาดการณ์และวางแผน: ใช้แนวโน้มระยะสั้น 10 ช่วงและ P95 พร้อมค่าเผื่อเติบโต ช่วยประเมินทรัพยากรที่ควรเตรียม

4.

จัดการอัตโนมัติอย่างควบคุมได้: เลือกเปิด AI RAM ราย Container และตั้ง Backup อัตโนมัติ พร้อมตรวจสอบผลผ่าน Action Log

03 จุดเด่นของระบบ

ติดตามแบบรวมศูนย์ รวม CPU / RAM / Disk, Risk Score, แนวโน้ม และสถานะเสถียรภาพไว้ใน Dashboard เดียว ดูค่าปัจจุบันเทียบค่าเฉลี่ยและพีค พร้อม Popup แจ้งเมื่อพบ Anomaly

ข้อมูลย้อนหลัง + คาดการณ์ เลือกเดือน วัน และชนิดทรัพยากรเพื่อเทียบค่าเฉลี่ยกับค่าสูงสุด ตรวจดูรูปแบบโหลดตามช่วงเวลา กราฟคาดการณ์แนวโน้มระยะสั้นจากข้อมูลที่สะสม

วางแผนจากสถิติ สรุปค่าเฉลี่ยและ P95 พร้อมเผื่อการเติบโต 20% เทียบเป้าหมาย CPU 70% / RAM 75% / Disk 80% และประเมินความจุที่ควรเตรียม ผู้ดูแลใช้เทียบกับสเปกปัจจุบันก่อนตัดสินใจเป็นคำแนะนำโดยประมาณ

AI RAM + Backup อัตโนมัติ เปิด AI RAM เป็นราย Container ได้ ระบบตรวจทุก 20 วินาที คำนวณ RAM limit จากการใช้จริงพร้อมเผื่อ 40% และไม่เกินเพดานที่กำหนด ส่วน Backup เปิดใช้ได้เมื่อเลือกโฟลเดอร์ ระบบสำรองทันทีและทำซ้ำทุก 1 ชั่วโมง เก็บชุดล่าสุด พร้อมดูผลใน Action Log
