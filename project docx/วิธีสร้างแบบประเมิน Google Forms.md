# วิธีสร้างแบบประเมิน Google Forms

สคริปต์จะสร้างแบบฟอร์มจากคำถามในภาคผนวก ฏ และตั้งค่าไม่เก็บอีเมลผู้ตอบ แบบฟอร์มเริ่มต้นเป็นฉบับร่างที่ยังไม่เผยแพร่ เพื่อให้ตรวจทานก่อนเปิดรับคำตอบ

1. เปิด [Google Apps Script](https://script.google.com/) ด้วยบัญชี Google ที่ต้องการเป็นเจ้าของแบบฟอร์ม
2. สร้างโครงการใหม่ แล้ววางเนื้อหาในไฟล์ `สร้างแบบประเมิน_Google_Forms.gs` ลงในตัวแก้ไข
3. เลือกฟังก์ชัน `createProjectAssessmentForm` แล้วกด Run และอนุญาตสิทธิ์ที่ Google แสดง
4. เปิด Execution log เพื่อดู URL แก้ไขและ URL สำหรับผู้ตอบ
5. ตรวจคำถามและการตั้งค่าผู้ตอบใน Google Forms แล้วกดเผยแพร่เมื่อพร้อมใช้งาน

เรียกฟังก์ชันซ้ำในโครงการเดิมจะเปิด URL ของแบบฟอร์มเดิม ไม่สร้างแบบฟอร์มซ้ำ
