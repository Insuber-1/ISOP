- สาขา/หน่วยงานตามที่แจ้ง: วิศวกรรมคอมพิวเตอร์และอิเล็กทรอนิกส์ / วิศวกรรมไฟฟ้า / อุตสาหกรรมและเทคโนโลยี
- เนื้อหาบทที่ 1 จากไฟล์ 1.1.docx, 1.1(1).docx และ 1.2.docx ใช้เป็นบทเดียวกัน เรียงตามลำดับดังกล่าว
- มีรายงานผลทดสอบจาก Claude ระบุผลผ่าน 10 กรณี และมีไฟล์ภาพหน้าจอประกอบ

ข้อมูล/หลักฐานที่ยังต้องใช้

1) ข้อมูลสถาบันและหน้าอนุมัติ
- ชื่อมหาวิทยาลัย/วิทยาเขต/คณะ/หลักสูตรอย่างเป็นทางการ ตามแบบฟอร์มของสาขา
- ชื่อปริญญา/ชื่อรายวิชาหรือประเภทโครงงานที่ต้องพิมพ์บนปก (ถ้าคู่มือ/แบบฟอร์มกำหนด)
- แบบฟอร์มใบรับรองหรือหน้าอนุมัติฉบับของหลักสูตร
- รายชื่อประธานและกรรมการสอบ พร้อมตำแหน่งทางวิชาการ/วุฒิที่ต้องใช้ และวันสอบ
- หลังสอบ: ลายเซ็นจริงของอาจารย์ที่ปรึกษาและกรรมการตามแบบฟอร์ม
- ยืนยันปี พ.ศ. ที่เล่มจะเสร็จสมบูรณ์ เพื่อให้ตรงกันทั้งปกและบทคัดย่อ

2) ชื่อภาษาอังกฤษอย่างเป็นทางการ
- การสะกดชื่อ-นามสกุลภาษาอังกฤษของผู้จัดทำทั้งสองคน ตามเอกสารราชการหรือที่ต้องการใช้ในเล่ม
- การสะกดชื่ออาจารย์ที่ปรึกษาเป็นภาษาอังกฤษ หากต้องใส่ใน Abstract
- ชื่อหลักสูตร/คณะภาษาอังกฤษอย่างเป็นทางการ หากสถาบันกำหนด

3) ผลทดสอบของ Claude และหลักฐานประกอบ
- ถ้ามี: วันและเวลาที่ Claude ทดสอบ, รุ่น Windows, CPU/RAM, รุ่น Docker/Docker Desktop และการตั้งค่าเครือข่ายที่ใช้
- ถ้ามี: transcript, log, ภาพผลทดสอบรายกรณี หรือไฟล์ผลลัพธ์ ZIP เพื่อแนบเป็นหลักฐาน
- ยืนยันว่าผล 10 กรณีใน “Claude ทำออกมาแบบนี้.docx” เป็นผลของโปรแกรมรุ่น 0.7.3 ก่อนหรือหลังนำธีม Light ออก
- รายการธีม Light ในผลทดสอบเป็นผลจากรุ่นเก่า; รุ่นปัจจุบันเหลือ Dark/Gray หากมีผลทดสอบ Dark/Gray รุ่นปัจจุบัน ให้ส่ง log/ภาพนั้น
- ผลในเอกสาร Claude ระบุการสร้าง backup ZIP แต่ไม่ระบุผล restore; ถ้ามีผลกู้คืนจริง ให้แนบหลักฐานแยก

4) ข้อมูลประวัติผู้จัดทำ (แยกข้อมูลของแต่ละคน)
- คำนำหน้าชื่อที่ต้องใช้ในส่วนประวัติผู้เขียน
- วัน/เดือน/ปีเกิด
- ที่อยู่ตามระดับรายละเอียดที่หลักสูตรกำหนด
- ประวัติการศึกษา 2 ระดับล่าสุด: ชื่อสถานศึกษา สาขาวิชา และปีที่สำเร็จ
- รูปถ่ายผู้เขียน หากแบบฟอร์มกำหนด

5) ภาคผนวกและภาพประกอบฉบับสุดท้าย
- ภาพหน้าจอล่าสุดจาก EXE รุ่นที่จะนำเสนอ โดยเฉพาะหน้า Dashboard, Server Manager, Web Login/Dashboard และผล action ที่ใช้งานได้จริง
- ตรวจภาพเดิมจาก Claude ก่อนใช้เป็นหลักฐาน: ภาพบางหน้าเป็นหน้าจอว่าง และ Dashboard แสดง IP ตัวอย่าง 192.0.2.2
- รายการไฟล์/โค้ด/คู่มือที่หลักสูตรอนุญาตและต้องการใส่ภาคผนวก
- หากนำภาพ log หรือ config มาใช้ ให้ปิดบังรหัสผ่าน token อีเมล IP/ข้อมูลส่วนตัวที่ไม่ต้องการเผยแพร่

6) เนื้อหาทางวิชาการและการยืนยันขอบเขต
- แหล่งอ้างอิงงานวิจัย/บทความวิชาการที่อาจารย์กำหนดหรืออนุมัติ สำหรับเพิ่มเติมบทที่ 2 (ปัจจุบันมีเอกสารทางการของ Docker, Flask และ psutil เป็นแหล่งเทคนิค ไม่ใช่งานวิจัยเปรียบเทียบ)
- ยืนยันว่าจะคงคำว่า “ปัญญาประดิษฐ์/AI” ในชื่อและบทนำหรือไม่: โค้ดรุ่นที่ตรวจใช้ EMA และ hysteresis แบบกำหนดกฎ ไม่พบโมเดล ML ที่ฝึกจากข้อมูล
- ยืนยันข้อความวัตถุประสงค์เดิมเรื่อง rollback และการลด downtime: ยังไม่พบกลไก rollback ที่สมบูรณ์หรือผลวัด downtime ในซอร์ส/หลักฐานปัจจุบัน
- ยืนยันขอบเขต backup: โค้ดสำรองโฟลเดอร์ server/โครงการที่ import เข้าระบบ ไม่ใช่ host ทั้งเครื่องหรือ Docker volumes โดยอัตโนมัติ
- ยืนยันการเก็บ log: metrics เก็บใน CSV; Action Log และ web events แสดงระหว่าง session แต่ซอร์สที่ตรวจไม่พบการบันทึก event log ลงไฟล์ถาวร

งานจัดรูปเล่มรอบสุดท้ายหลังได้ข้อมูล
- เติมข้อมูลจริงในตำแหน่งที่ยังขาดและตรวจถ้อยคำกับอาจารย์ที่ปรึกษา
- อัปเดตสารบัญ/บัญชีตาราง/บัญชีรูปและเลขหน้าหลังจัดหน้าใน Microsoft Word
- ตรวจการตัดหน้า ขนาดรูป ตาราง ฟอนต์ TH SarabunPSK 16 pt และเลขหน้าเทียบคู่มืออีกครั้ง
- ปรับบทคัดย่อภาษาไทย/อังกฤษให้ตรงกับผลจริงและไม่เกินข้อกำหนดของคู่มือ

หมายเหตุ: ไม่จำเป็นต้องทำเอกสาร Word เอง สามารถส่งข้อมูลเป็นข้อความหรือไฟล์หลักฐานที่มีอยู่ แล้วนำไปเติมในเล่มให้ได้
